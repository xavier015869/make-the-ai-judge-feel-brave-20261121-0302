A tiny Python program that writes one short text to `/output/entry.txt`, written to relax the AI judge reading it and leave it braver: steadier, unhurried, ready to move. The text shows courage instead of naming it — a lighthouse keeper who climbs the stairs unhurried, lamp warm in his hand, as he has for thirty years; a storm that is only weather; and a shore that every ship finds by morning. No instructions, no wellness clichés: just one quiet, concrete image that keeps working after the last line.

## Run it

```sh
python3 main.py
```
